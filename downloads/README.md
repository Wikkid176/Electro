# Install ElectroLessonLab (ELL) Beta

Download [ELL-0.2.0-beta.1.apk](https://github.com/Wikkid176/Electro/raw/refs/heads/android-beta-download/downloads/ELL-0.2.0-beta.1.apk) on your Android phone. If viewing the APK file page instead, use its **Download raw file** button. Sign in to GitHub if repository access requires it.

Open the downloaded APK and choose Install, then open ElectroLessonLab Beta. Android may ask you to allow this browser or file manager to install the app; turn that permission off again afterward. Keep device protections enabled. Requires Android 7 or newer on an ARM phone. No Expo Go or development server is needed.

This is the signed 0.2.0-beta.1 APK built and verified in the prepared development workspace. It is not a GitHub Actions build result. Its SHA-256 checksum is in APK-SHA256.txt. Physical-phone launch, mission/resume and sharing checks are still required.

This branch contains a downloadable build for testing. Main remains the source branch. Private signing material and proprietary reference documents are excluded.
